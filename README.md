Tic Tac Toe Game

A console-based Tic Tac Toe game developed in C++ to demonstrate core programming concepts such as loops, arrays, conditional logic, and game logic.

Features

- Two-player console gameplay
- Dynamic 3×3 game board
- Player X and Player O turns
- Win detection for rows, columns, and diagonals
- Draw detection
- Invalid move handling
- Replay option
- Simple and interactive console interface

Concepts Used

- C++ programming
- Arrays
- Loops
- Conditional statements
- Functions
- Character variables
- Game logic

How to Play

1. Player X starts the game.
2. Enter a number from 1 to 9 to select a position.
3. Player O takes the next turn.
4. The first player to complete a row, column, or diagonal wins.
5. If all positions are filled without a winner, the game ends in a draw.
6. Players can choose to play again after each game.

Expected Outcome

An interactive console-based Tic Tac Toe game with dynamic board display, win/loss detection, draw detection, and replay functionality.
